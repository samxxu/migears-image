# P1-1 — `save()` returns `false` on a write failure and leaks a raw PHP …

## Finding / 问题

- EN: `save()` returns `false` on a write failure and leaks a raw PHP warning, while `README.md` promises that all failures throw `ImageException`; the sibling `output()` does throw. The fix forks on a decision — document the bool, or make it throw, which breaks callers that test the return value.
- 中文: `save()` 在写入失败时返回 `false` 并漏出原始 PHP 警告，而 `README.md` 承诺所有失败都抛 `ImageException`；兄弟方法 `output()` 确实会抛。修复分岔于一个决定——把 bool 写进文档，或改成抛异常，而后者会打断那些判断返回值的调用者。
- Where / 位置: `src/GDImage.php:252-261 · src/GDImage.php:339`
- Verification / 验证: reproduced / 已实证
