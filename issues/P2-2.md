# P2-2 — save() suppresses the raw warning on the write but not on the mkdir …

## Finding / 问题

- EN: save() suppresses the raw warning on the write but not on the mkdir that precedes it, so when the parent path cannot be created the caller first sees a raw PHP warning and only then the documented ImageException; under a warning-to-exception handler it gets an ErrorException instead. The sibling TemplateCompiler::compileToCache() prefixes both mkdir and file_put_contents with @, so the discipline exists in the project.
- 中文: save() 对写入抑制了原始警告，但对之前的 mkdir 没有：父路径无法创建时，调用方先看到原始 PHP 警告、之后才拿到文档承诺的 ImageException；在「警告转异常」配置下则拿到 ErrorException。同族的 TemplateCompiler::compileToCache() 对 mkdir 与 file_put_contents 都加了 @，可见这套纪律在本项目里是存在的。
- Where / 位置: `src/GDImage.php:257`
- Verification / 验证: reproduced / 已实证

The gap was real and narrow: `save()` prefixed the write with `@` but left the `mkdir()` before it bare, so a parent path that cannot be created leaked `mkdir(): File exists` before the documented exception. The call site is now `@mkdir($dir, 0755, true)` (`src/GDImage.php:259`), the same idiom as the write at `src/GDImage.php:264` and `textWatermark()`; the cited `src/GDImage.php:257` has drifted by two lines since filing, and nothing else in `save()` changed. Regression test `tests/GDImageTest.php::testSaveReportsUncreatableDirectoryByThrowingWithoutAWarning` places a regular file where the parent directory should be: with the `@` reverted the suite is red — `./vendor/bin/phpunit --do-not-cache-result` exit 1, `Tests: 106, Assertions: 218, Warnings: 1`, the warning attributed to `src/GDImage.php:257`; restored, exit 0, `OK (106 tests, 218 assertions)`. Re-reproduced through the module's own autoloader in a temp dir outside the repo, counting only the warnings a caller actually sees — PHP 8 still calls a user error handler for an `@`-suppressed error, so the handler has to read `error_reporting()` back or the count overstates: before `handler hits: 1`, `warnings the caller actually sees: 1` (`mkdir(): File exists`); after `handler hits: 1`, `warnings the caller actually sees: 0`. `./vendor/bin/phpstan analyse --no-progress` and `composer validate` exit 0 both before and after.
